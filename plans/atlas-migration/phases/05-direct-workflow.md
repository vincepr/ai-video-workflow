# 05: Orchestrate the automatic direct-ad workflow

## Read

Phases 02-04 handoffs; selected direct guide and recipes; extraction's direct app mapping; existing generation lessons and physical-fidelity guide. Read actual product facts only in the assigned local verification run, not in generic implementation fixtures.

## Work

1. Connect the skill and Python operations into the direct path: configured references/brief, agent-authored image/video prompts, first frame, internal agent inspection/selection, one planned video job, raw inspection and finishing handoff.
2. Run the whole configured sequence after the original Generate action. Human stage confirmation is optional. Internal agent review is real image/frame inspection, not a success flag from the API or a Python script claiming it inspected visuals.
3. Record the selected frame's provenance, source hashes and inspection decision before submitting motion. Validate actual image dimensions, masks/crops, inventory where relevant and ending bounds if using both anchors. Do not use sample-specific repair coordinates as a generic algorithm.
4. Preserve creative intent from the selected format/hook/setting while respecting product facts and provider controls. Check that no-presenter recipes remain no-presenter and that sound/dialogue choices match the recipe. Avoid rebuilding the same rejected creative as a default.
5. Handle failure without unplanned spend. Local edits or reuse may continue within the configured request; an unbudgeted paid correction or model change stops for a new user decision. Pending jobs resume; they do not trigger another image/video purchase.
6. Produce a structured run review separating technical compatibility, accepted motion ranges, edited output and creative verdict. The preferred example used selected motion and local holds; do not turn that salvage into an undocumented mandatory recipe for every ad.

## Ownership

Direct workflow orchestration, prompt/artifact handoff and acceptance tests. Keep generic execution independent of any one product, slogan, font color or camera repair. Use recorded responses and synthetic media first; no paid generation is authorized by this migration runbook.

## Gate

An offline automatic run executes from one frozen request without human checkpoints, loads exactly the selected configuration, retains stage decisions and returns a finishing-ready plan. A presenter recipe and a no-presenter recipe produce coherent, distinct prompts. Resume does not redo accepted work.

## Handoff

Return automatic-run entry point, context evidence, run-state example, prompt and inspection artifacts, reusable accepted-media fixtures, and the finishing contract. Mark live generation unverified unless a separate user-authorized test actually occurred.
