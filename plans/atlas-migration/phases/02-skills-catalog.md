# 02: Create modular skills and configuration context

## Read

Phase 01 interface handoff; skill-creator; existing generate-product-video and create-short skills. Read upstream formats, hooks, settings, examples and the extraction's app-options/source-mapping references. Preserve physical-fidelity and destination guides.

## Work

1. Extend the existing product-video skill into a concise router driven by the frozen request. It loads one family guide and the resolver's selected files. Do not make a skill per format or copy every recipe into SKILL.md.
2. Put workflow mechanics in family guides, creative enrichment in independent recipe files, and executable operations in Python utilities. Guides instruct the agent how to plan, inspect, execute and record outcomes; recipe files describe composition, movement, pacing, sound and ending.
3. Preserve the complete direct catalog: 16 formats, 12 hooks including None, 12 settings including Auto. Preserve the six skit styles and six drama styles in workflow-specific metadata, without claiming those pipelines already work.
4. Keep a compact catalog index for UI discovery and context-path resolution. Store stable upstream IDs, labels, applicability, required inputs, version and source provenance. Recipe bodies are separate. Use independently authored instructions where copy terms are unresolved.
5. Resolve presenter/selfie conflicts explicitly. Hyper Motion is no-presenter commercial; no generic selfie or spoken recommendation should leak into its context. Preserve product facts and distinguish surreal styling from real feature/scale claims.
6. Define common output expectations: actual prompt files, first-frame selection/provenance, stage decisions, raw outputs, edit plan, review and final artifact pointers. Configure once and execute planned stages automatically; optional human checkpoints are a selected execution mode.

## Ownership

Skill router, family instruction files, selected-context recipe files and catalog index. Coordinate Python script paths with phase 03, but do not change their implementation concurrently. Keep old skill entry points compatible while the engine is incomplete.

## Gate

Run the skill-creator validator. Test catalog IDs/counts and resolvable selected paths. Review at least Hyper Motion+Bizarre, a presenter UGC recipe and an ASMR recipe for distinct instructions and no irrelevant context. A new format can be added as data without editing the runtime.

## Handoff

Return catalog path/version, recipe provenance, router invocation, selected-context examples, instruction review and validator results. Distinguish configured recipes from available or live-verified provider routes.
