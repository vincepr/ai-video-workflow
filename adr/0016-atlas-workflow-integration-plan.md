# 0016: Plan recipe-driven product video workflows

Status: Proposed
Date: 2026-10-14

## Proposal

Integrate the extracted Atlas agent workflow as a reusable creative engine.
Keep workflow families, creative recipes and provider execution separate.
Retain existing project intake, review, numbered exports and release records.
Default to configure, generate the planned stages automatically, then refine.
Intermediate human checkpoints are optional; use a fixed run budget upfront.
Start with the tested direct-ad path and its full format/hook/setting catalog.
Then add skit, drama and reference-remake pipelines when their required
provider capabilities are verified. Preserve explicit unsupported states.

Reuse the existing local executor initially. Parameterize its finishing
and path assumptions before adding UI controls. Shared video-shot rendering
has separate implementation scope; the current renderer accepts stills.
Planning does not authorize generation, publication or another paid service.

Source: AtlasCloudAI/atlas-marketing-studio at
18ec178052f6f97612813997613d88ce34b02fc5. Verify reuse terms before porting.
See [the phased plan](../plans/atlas-workflow-integration.md).
Product-specific evidence stays local and is not part of this proposal.

## Validation

Reproduce the existing edited baseline from saved media without paid calls.
Check distinct recipe plans, reference roles, presenter rules and capabilities.
Verify project isolation, global key budget reservations and job recovery.
Preserve raw output and inspect final typography, product detail and audio.
Validate one user-authorized example per supported workflow family.
Run npm run check; render and inspect samples for implemented visual changes.
Do not label untested presets or unavailable modes as verified.
