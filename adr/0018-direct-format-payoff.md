# 0018: Plan the visible payoff of each direct format

Status: Accepted
Date: 2026-10-15

## Decision

Each direct format recipe states an opening state, signature action and visible payoff. The agent's first-frame and motion prompts must carry those beats. Before generation, judge the outline with captions muted: the action should still identify the chosen format. A plausible product action is insufficient when it removes the requested transformation, reveal, test or interaction.

Showcase clips communicate creative intent but are not provider motion references unless the selected route explicitly sends them. Keep product identity and factual claims separate from visual effects. A concept-test model may be used to check the payoff, while a final ad needs its own continuity review and current model cost comparison.

## Reason

A Mess to Fresh attempt showed a correct product and a plausible hand action but missed the large before-and-after effect. A later low-cost effect test showed the intended payoff while moving stable objects and changing product details. The same mismatch can occur in other format choices when the recipe specifies only a look or a small action.

## Validation

For each future direct-ad plan, compare the outline, opening frame and motion prompt to the selected recipe's signature beat before paid submission. Inspect intermediate frames and the final state against the same beat and product reference. Record any mismatch in that project's ignored review folder. This decision changes instructions only; no provider run is required to adopt it.
