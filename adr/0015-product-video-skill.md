# 0015: Route generated product videos by destination

Status: Accepted
Date: 2026-10-13

## Decision

Add generate-product-video for product-reference video research and production.
Keep its shared generation guidance separate from private, organic social,
paid advertising and shop-page references. Load the destination guides needed
for the requested output. Relaxdays is a merchant example, not an assumed partner.

Store current model comparisons, product facts and cost estimates in the assigned
project with dated sources. The skill requires refreshed provider and destination
checks rather than embedding a permanent model ranking or platform permission.
Source intake includes descriptions, specifications, gallery images and available
product videos from supplied material or web sources, with inspection and source records.

Do not extend the still-image renderer as part of research. Provider connections
and shared video-shot support have separate implementation scope. Production and
publication authorization remain separate from a reusable workflow request.

## Validation

Run the skill-creator validator and npm run check. Review each destination's routing
against a private test, organic brand post, paid campaign and merchant product page.
Verify all linked references exist. Check that project research records actual
provider controls and costs, and that media stays ignored by Git.
