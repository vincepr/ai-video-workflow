# Voice

Use the current options and operating roles in ADR 0006. Follow ADR 0004 before API use.

- Let the user supply browser-generated recordings. Copy them into ignored local media; preserve the original audio.
- Align captions, cuts and animation to each recording. Different voices can change duration and cadence even with the same script.
- When comparing voices, keep images and commentary consistent or identify differences. Save each version separately.
- Use local speech for scratch drafts when no recording is supplied. Do not replace a chosen recording with scratch speech during production.
