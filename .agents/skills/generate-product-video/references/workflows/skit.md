# Ad skit

Develop a short scene with a setup, product-related turn and payoff in the selected style. Keep cast, location and dialogue consistent across planned shots. Write the script and stage prompts as separate artifacts so a rejected line can be revised without obscuring image and video provenance. A performer image is optional only when the selected route can create a stable cast without it; never imply identity continuity was verified from a script alone.

Inspect first frames and raw clips before finishing. Record the script version, casting/reference decisions, timing, dialogue or voice source, local edit plan and final pointers. Current catalog configuration does not establish a live script, image or video provider route; stop at unsupported if the requested stages cannot be validated.
